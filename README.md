# הגרלת חג הגאולה י"ט-כ' כסלו תשפ"ז — מרכז חב"ד עפולה

אתר לרכישת כרטיסי הגרלה (25 ₪ לכרטיס) להתוועדות המרכזית, יום שני כ' כסלו (30.11), 19:30, אולמי פאר בראשית.

- **דף רכישה** (`index.html`): בחירת כמות, פרטי מזמין, שם נפרד לכל כרטיס, קוד מורשה, תשלום באייפרם של נדרים פלוס.
- **ממשק ניהול** (`admin.html`): סטטיסטיקות, טבלת משתתפים, ניהול קודי מורשים, אישור ידני להזמנות תקועות, SMS חוזר, ייצוא CSV.
- **שרת** (`apps-script/Code.gs`): Google Apps Script שמחובר לגיליון Google Sheets. **כל כרטיס נשמר בשורה נפרדת** בלשונית "כרטיסים".

## איך זה עובד

1. הלקוח ממלא את הטופס. השרת שומר הזמנה בסטטוס `pending` ופותח עסקה בנדרים פלוס **בצד השרת**, כך שאי אפשר לשנות את הסכום מהדפדפן.
2. אייפרם נדרים פלוס (v3) נפתח עם `TransactionId` + `Key` בלבד. אפשר לשלם באשראי, בביט, ב-Google Pay או ב-Apple Pay.
3. נדרים פלוס שולחים **CallBack** ישירות ל-Apps Script עם `Param2` (מזהה הזמנה סודי שלא נחשף לדפדפן) ועם הסכום. רק אז נוצרות שורות הכרטיסים ונשלחים SMS ומייל.
4. בקוד מורשה תקין: הכרטיסים נרשמים מיד, בלי תשלום.

התשלום נרשם בנדרים פלוס בקטגוריה (`Groupe`): **הגרלה יט כסלו תשפז**.

### לשוניות בגיליון (נוצרות אוטומטית)

| לשונית | תוכן |
|---|---|
| כרטיסים | שורה לכל כרטיס: מס' כרטיס, תאריך, שם על הכרטיס, משלם, טלפון, מייל, ת"ז, אופן רישום, אסמכתא, סכום, מס' הזמנה |
| הזמנות | כל הזמנה וסטטוס התשלום שלה (pending / paid / failed) |
| מורשים | שם מורשה, קוד, מגבלת כרטיסים, פעיל |
| לוג | CallBack-ים מנדרים, שגיאות SMS ומייל |

מספור הכרטיסים מתחיל ב-1001, והוא רץ תחת נעילה כדי שלא ייווצרו שני כרטיסים עם אותו מספר.

## התקנה (פעם אחת)

### 1. גיליון + סקריפט
1. יוצרים Google Sheet חדש, למשל "הגרלת יט כסלו תשפז".
2. **הרחבות → Apps Script**. מדביקים את תוכן `apps-script/Code.gs`.
   ב-⚙️ הגדרות הפרויקט מסמנים "הצגת קובץ המניפסט appsscript.json" ומדביקים את `apps-script/appsscript.json`.
3. בעורך בוחרים את הפונקציה `setup` ולוחצים **הפעלה**. מאשרים את ההרשאות, והלשוניות נוצרות.

### 2. הגדרות סודיות (לא בקוד ולא בגיט)
⚙️ הגדרות הפרויקט → **Script properties**:

| מפתח | ערך |
|---|---|
| `ADMIN_PASSWORD` | סיסמה לממשק הניהול |
| `YEMOT_TOKEN` | (לשליחת SMS) טוקן API של ימות המשיח |
| `YEMOT_SMS_FROM` | (אופציונלי) שם שולח מאושר בימות, למשל `חבד עפולה` |
| `WEB_APP_URL` | כתובת ה-Web App משלב 3 |

### 3. פריסה כ-Web App
**פריסה → פריסה חדשה → Web app**: Execute as **Me**, Who has access **Anyone**.
מעתיקים את הכתובת שמסתיימת ב-`/exec`:
- שומרים אותה ב-Script property `WEB_APP_URL`, כי זו כתובת ה-CallBack לנדרים.
- מדביקים אותה ב-`assets/config.js` בשדה `API_URL`.

> בכל שינוי בקוד: **פריסה → ניהול פריסות → עריכה → גרסה חדשה**. כך הכתובת נשארת אותה כתובת.

### 4. אחסון האתר
האתר סטטי (HTML/CSS/JS), ואפשר לארח אותו ב-GitHub Pages, ב-Netlify או ב-Vercel.
- **GitHub Pages:** Settings → Pages → Deploy from branch → `main` / root. (בריפו פרטי נדרש חשבון GitHub בתשלום. אפשרות אחרת היא Netlify או Vercel, שמתחברים לריפו פרטי בחינם.)

## בדיקה לפני פרסום
1. בממשק הניהול מוסיפים קוד מורשה לבדיקה, נרשמים איתו מדף הרכישה, ובודקים שנוצרה שורה לכל כרטיס בלשונית "כרטיסים" ושהגיע SMS.
2. מבצעים רכישה אמיתית של כרטיס אחד ב-25 ₪, ובודקים:
   - בלשונית "לוג" מופיע `nedarim_callback`.
   - ההזמנה עברה ל-`paid`, ונוצרה שורת כרטיס עם מספר העסקה.
   - בנדרים פלוס העסקה מופיעה בקטגוריה "הגרלה יט כסלו תשפז".
3. אחר כך מבטלים או מזכים את עסקת הבדיקה בנדרים פלוס, ומוחקים את השורה מהגיליון.

## אם ה-CallBack לא הגיע
נדרים פלוס שולחים את ה-CallBack פעם אחת בלבד. אם הלקוח שילם וההזמנה נשארה "ממתינה", היא תופיע בממשק הניהול תחת **הזמנות שממתינות**, יחד עם הערה אם הדפדפן דיווח על תשלום תקין. בודקים בנדרים פלוס שהעסקה עברה, לוחצים **אשר ידנית** ומזינים את מספר האסמכתא. הכרטיסים נוצרים, ונשלחים SMS ומייל.

## אבטחה
- מספר המוסד ו-ApiValid מוגדרים בקוד השרת (לא סודיים). טוקן ימות וסיסמת הניהול שמורים רק ב-Script properties, ולא נשלחים לדפדפן.
- הסכום ננעל בשרת (CreateTransaction). לדפדפן אין דרך לשנות אותו.
- כרטיסים בתשלום נוצרים רק מ-CallBack שמכיל מזהה הזמנה סודי וסכום תואם.
- סיסמת הניהול נבדקת בשרת. אחרי 10 ניסיונות שגויים הכניסה ננעלת ל-10 דקות. כל כניסה בתוקף ל-6 שעות.
- כל הטקסט שהגולשים מזינים מוצג כטקסט בלבד (מוגן מ-XSS), ונשמר בגיליון בלי אפשרות להזריק נוסחאות.
